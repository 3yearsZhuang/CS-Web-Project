# Design Lab — FztbuCS 设计语言探索

> 对 CS-Web-Frontend 现有设计语言「编辑式技术极简」的完整提取（V0 刻板印象版），
> 以及三个方向的系统性优化提案（V1 / V2 / V3）。
> 每版均为独立可打开的 HTML 原型（含交互、动效、响应式），直接用浏览器预览即可。

## 目录

| 版本 | 路径 | 一句话定位 |
|---|---|---|
| V0 刻板印象版 | `v0-stereotype/index.html` | 现有设计语言的忠实复刻（基准线） |
| V1 精进编辑式 | `v1-refined-editorial/index.html` | 延续 DNA 的进化版 — 最安全、可直接落地 |

## 0. 现有语言 DNA 提取（V0 复刻了什么）

从 `src/app/globals.css`、`src/app/page.tsx` 提取的设计基因：

| 维度 | 现状 |
|---|---|
| 名称 | 编辑式技术极简（Editorial Tech Minimalism） |
| 浅色主题 | 浅粉底 `#fdf5f7` + 深黑紫文字 `#1e1233` + 深蓝强调 `#1e40af` |
| 深色主题 | 纯黑 `#000` + 暖白 `#f5f5f4` + 琥珀金 `#d4a574` |
| 字体 | Fraunces 展示衬线（字重 350）/ Manrope 正文 / JetBrains Mono 元数据（11px uppercase） |
| 版式 | 12 栏可见栅格、数字章节标记 `[ 00 ]`、工业双斜杠 `//`（ark-divider）、角标 `[ ]`、1px 发丝线 |
| 组件 | 直角方形按钮、mono 12px uppercase 字、卡片仅 border 变色反馈 |
| 动效 | `cubic-bezier(0.16,1,0.3,1)`、clip-path 揭示、字符级动画、呼吸状态点 |
| 品牌 | 粉蓝渐变 logo 色板（黎明日出色调）、莫比乌斯环粒子 |

**V0 的诚实评价** — 这套语言已经相当成熟（token 化、双主题、动效守卫齐全），
但存在五个可改进的结构性问题，正是 V1–V3 的出发点：

1. **浅粉底的气质错位**：`#fdf5f7` 偏"少女感"，与"计算机协会"的技术身份有割裂；
2. **字阶断层**：Hero 180px 与正文 16px 之间没有中间层级，页面只有"极大"和"极小"；
3. **节奏平**：全页浅色 + 发丝线 + 白卡，缺少明暗起伏，扫读时没有视觉锚点；
4. **交互反馈弱**：卡片 hover 仅边框变色，是"装饰性反馈"而非"内容性反馈"；
5. **深色纯黑刺眼**：`#000` 在 OLED 上产生光晕，且琥珀金一色承担全部语义。

## V1 · 精进编辑式 — 在 DNA 上进化（推荐优先落地）

**思路**：不推翻，而是逐一修复上述五个问题。迁移成本最低，视觉收益最大。

| 改动 | 现有 → V1 | 为什么更好 |
|---|---|---|
| 浅色底 | `#fdf5f7` 浅粉 → `#faf9f6` 中性暖纸 | 保留温度、摆脱少女感，与"技术社区"气质对齐 |
| 文字色 | `#1e1233` 黑紫 → `#17150f` 墨黑 | 对比度 8.6:1+，正文长时间阅读更稳 |
| 深色底 | `#000` 纯黑 → `#131318` 墨灰 | 消除 OLED 光晕刺眼；琥珀金调暖 `#e2b98c` |
| 字阶 | 事实上的 3 级 → 完整 8 级（11/13/16/20/28/40/64/104） | 补齐 Hero 与正文之间的断层，层级可复用 |
| 页面节奏 | 全页浅色 → 中部插入深墨蓝锚点区块 | "明—暗—明"节奏，扫读有锚点，深色区块呼应深色主题 |
| 卡片反馈 | 边框变色 → 大索引号 + 箭头位移 + 微浮起 | 反馈从装饰升级为内容驱动，引导点击 |
| 信息效率 | 无 → 数据带（成员/活动/项目/历史） | 社区实力一眼可达，首页从"宣传页"变"事实页" |
| 按钮 | 仅透明度变化 → 微浮起 + 主题色投影 | 主操作的可达性（affordance）显著增强 |

**落地路径**：V1 的全部改动都可映射为 `globals.css` 的 token 调整 + 少量组件升级，
不触碰布局结构，可分批灰度上线。

## V2 · 墨蓝终端 — 深色优先 × 工程仪表盘

**思路**：换一个提问方式 —— 我们的用户（CS 学生）一天 10 小时活在终端和编辑器里，
为什么官网要假装自己是一本杂志？让"终端"成为身份本身。

| 设计决策 | 为什么更好 |
|---|---|
| 深色优先，深墨蓝 `#0b1017` 替代纯黑 | 比现有深色主题更护眼；对目标用户（开发者）是"母语环境" |
| 双语义强调色：青 `#5eead4` = 信息/成功，琥珀 `#f5b86b` = 状态/警示 | 修复现有深色主题"琥珀一色到底"的语义缺失；状态一目了然 |
| Hero = 一段真实可读的终端会话（`whoami` / `ls ./tracks` / `./join --apply`） | 用三行命令讲完协会是谁、有什么、怎么加入——比抽象 slogan 高效一个量级，且极具社区认同感 |
| 仪表盘数据带（在线成员 / 本周 commits / OJ 提交 / 进行中活动） | 社区被呈现为"活的系统"而非静态宣传册；这些数字后端本来就有 |
| 事件列表 = log（时间戳 + 级别 tag + 消息） | 与终端心智模型一致；`tail -f` 的隐喻暗示"持续更新" |
| 按钮文案 `git clone 加入我们` | 细节处的身份幽默，目标用户会心一笑 |

**代价**：彻底换肤，组件库需要重做；浅色主题降级为次要场景。
**适合**：如果社区定位为"硬核工程社团"，这是身份最锋利的一版。

## V3 · 暖纸人文 — 杂志叙事 × 东方书卷气

**思路**：再换一个提问方式 —— 技术社区最稀缺的资产不是代码，是人。
如果官网是一本"人的杂志"会怎样？

| 设计决策 | 为什么更好 |
|---|---|
| 米纸 `#f6f2e9` + 墨黑 + 朱红印章色 `#b3422f`（<5% 点睛） | 比浅粉底更有书卷气与沉淀感；朱红成为独一无二的品牌记忆点 |
| 中文衬线（Noto Serif SC 900）成为绝对主角 | 现有系统里中文衬线只是 Fraunces 的附属配对；本版证明中文大标题的书写感本身就是顶级设计资源 |
| 章节用「第壹章 / 第贰章」替代 `[01] [02]` | 弱化工业感、强化人文连续性，与"卷首 / 雅集 / 庭园"的文案体系自洽 |
| 非对称杂志栅格（5:4:3 错落、纵向偏移） | 打破 12 栏机械均分，阅读动线由内容重要性驱动而非栅格驱动 |
| 首页主角 = 人物故事（Hackathon 之夜、读书会领读人、第一个 PR） | 招新转化的心理路径是"我想成为那样的人"，而非"这个社团有 3 个部门" |
| 印章、直排文字、纸纹 | 在所有大学技术社团中建立零撞车的视觉识别 |

**代价**：离现有系统最远，且对内容运营要求高（需要持续产出故事）。
**适合**：如果协会希望以"文化氛围"作为差异化招新卖点。

## 三版横向对比

| 维度 | V1 精进编辑式 | V2 墨蓝终端 | V3 暖纸人文 |
|---|---|---|---|
| 与现有语言关系 | 进化（80% 保留） | 换肤（30% 保留） | 重构（10% 保留） |
| 落地成本 | ★ 低（token 级改动） | ★★★ 高（组件重做） | ★★★★ 高 + 内容运营 |
| 身份表达 | 专业、克制 | 硬核、极客 | 人文、温度 |
| 信息效率 | 高（数据带） | 最高（仪表盘） | 中（叙事优先） |
| 品牌独特性 | 中 | 高 | 最高 |
| 招新转化逻辑 | "这个社团很专业" | "这是自己人" | "我想成为他们" |
| 深色体验 | 修复纯黑问题 | 深色即主场 | 未覆盖（浅色单主题） |

**建议**：以 V1 为近期迭代基线（低风险高收益），
把 V2 的"仪表盘数据带"和 V3 的"人物故事板块"作为模块嫁接到 V1 骨架上，
即可兼得三版之长。
