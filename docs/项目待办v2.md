## Agent 工作台专项：全量学习助理路线

### 目标与边界

将现有 Auxilio 从“工作台内的流式问答组件”演进为贯穿学习、项目和社区的个人 Agent：

1. **学习闭环**：考试结果 -> 薄弱点 -> 资源/练习推荐 -> 学习计划 -> 专注执行 -> 复盘调度。
2. **项目闭环**：GitHub 活动 -> 变更理解 -> 风险/停滞识别 -> 小步迭代建议 -> 经确认创建任务或草稿。
3. **社区闭环**：社区新内容 -> 订阅过滤 -> 摘要/去重 -> 个性化推荐 -> 经确认参与讨论或联系成员。
4. **工作台闭环**：Agent 不只存在于聊天卡，而是通过建议收件箱、每日简报、上下文入口和自动化规则连接所有 widget。

执行边界：

- 读取、分析、总结类能力可在用户授权的数据域内自动执行。
- 修改站内个人数据必须可预览、可撤销并写审计日志。
- 创建 Issue、发布社区内容、发送消息等外部或代表用户发声的行为必须逐次确认。
- 不允许模型直接访问 ORM、数据库或任意 Service；所有能力必须经过有 schema、权限和审计的 Skill。
- 外部网页、社区正文、仓库内容均视为不可信输入，不能提升为系统指令。
