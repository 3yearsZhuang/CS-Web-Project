## 场景 A：完成 ICP 备案申请并通过审核（目标：备案号下发并在网站底部公示）

**适用**：将网站上线前的合规备案工作作为一个独立目标完成。

### A.1 操作步骤（8 步）

#### A.1-1 准备备案前置材料（MUST 全部就绪）

在开始线上申请前，**MUST** 准备好以下 7 项材料：

| # | 材料名称 | 要求 | 获取方式 |
|---|---|---|---|
| 1 | **已实名的域名** | 域名所有者与主办单位一致；域名有效期 ≥ 6 个月 | 域名注册商（阿里云/腾讯云等）控制台 |
| 2 | **主办单位证件** | 事业单位法人证书 / 社会团体法人登记证书（彩色扫描件，清晰可辨） | 单位行政部门 |
| 3 | **网站负责人证件** | 身份证正反面彩色扫描件；手机号、电子邮箱（个人信息） | 个人准备 |
| 4 | **服务器信息** | 服务器 IP 地址（**MUST 中国大陆境内**）、服务器所在地、接入服务商名称 | 服务器提供商控制台 |
| 5 | **域名证书** | 域名实名认证截图（证明域名归属） | 域名注册商控制台 |
| 6 | **主办单位人脸核验** | 网站负责人手持身份证或在线人脸识别截图 | 备案系统提供的核验环节 |
| 7 | **系统功能说明文本** | 用于填写"网站服务内容描述"（≥ 15 字） | **引用本文附录 A.1 预写文本** |

**成功标准**：7 项材料全部以电子文件形式准备就绪，文件名清晰（如 `domain_auth.pdf`、`legal_cert.jpg`）。

#### A.1-2 登录备案系统并选择"新增网站备案"

1. 访问工信部备案系统（https://beian.miit.gov.cn/）或通过接入服务商（如阿里云/腾讯云）的备案代办入口登录。
2. 点击「备案」→「新增网站备案」（或类似入口）。

#### A.1-3 填写主体信息（主办单位 + 网站负责人）

**操作指令**：
- **主办单位**：填入与证件完全一致的名称、单位性质（事业单位/社会团体）、证件号码。
- **网站负责人**：填入负责人姓名、证件号码、联系电话、电子邮箱。
- **人脸核验**：按系统提示完成在线人脸识别。

**成功标准**：主体信息页面所有字段填写完毕，人脸核验通过（提示"核验成功"）。

#### A.1-4 填写网站信息（核心步骤，MUST 准确）

**操作指令**：
- **网站名称**：`计算机协会官网`（或按社团官方名称填写）。
- **网站域名**：填入已实名的完整域名（如 `cs.example.edu.cn`）。
- **服务器 IP 地址**：填入境内服务器的**公网 IP**（`MUST NOT` 填内网 IP 或 `localhost`）。
- **接入服务商**：选择服务器对应的接入服务商（如阿里云、腾讯云）。
- **网站类型**：选择"非经营性互联网信息服务"。
- **前置审批**：选择"无"（本项目不涉及新闻、出版、教育等前置审批行业）。
- **网站服务内容描述**：**MUST** 使用附录 A.1 提供的预写文本，或根据实际情况修改（≥ 15 字，清晰描述网站用途）。

**成功标准**：网站信息页面所有字段填写完毕，系统校验通过（无红色提示）。

#### A.1-5 上传证件材料

**操作指令**：
- 按系统要求上传主办单位证件、网站负责人身份证、域名证书等扫描件。
- **MUST** 保证图片清晰、完整，边角无遮挡，文字可辨。

**成功标准**：所有材料上传成功，系统预览可正常查看。

#### A.1-6 提交审核

**操作指令**：
- 仔细核对所有已填信息（**SHOULD** 使用末尾「备案信息确认清单」逐项检查）。
- 确认无误后点击「提交审核」。

**成功标准**：系统提示"提交成功"，备案申请状态变为"待审核"。

#### A.1-7 等待审核与补充材料

**操作指令**：
- 通常审核周期为 **5–20 个工作日**。
- 审核期间保持手机畅通，邮箱可用；管局可能通过电话或邮件要求补充材料。
- 若收到"退回修改"通知，**MUST** 在 15 日内修改并重新提交。

**成功标准**：备案状态变为"审核通过"，系统生成备案号。

#### A.1-8 公示备案号

**操作指令**：
- 拿到备案号后，**MUST** 在网站底部（Footer）添加备案号文本及工信部链接。
- 若后续开通公安备案，**MUST** 在备案完成后 30 日内办理公安联网备案。

**成功标准**：访问网站首页，底部显示形如 `京ICP备XXXXXXXX号` 的备案号，点击可跳转到工信部备案查询页。

### A.2 成功标准（提交前 MUST 逐项自检）

在提交审核前，**MUST** 使用以下清单确认所有信息准确无误：

- [ ] **主办单位全称**：与法人证书完全一致（无简称、无错别字）
- [ ] **单位性质**：正确选择（事业单位 / 社会团体）
- [ ] **网站负责人**：姓名、证件号、电话、邮箱全部正确
- [ ] **域名**：已实名认证，所有者与主办单位一致
- [ ] **服务器 IP**：中国大陆境内公网 IP（非内网、非境外）
- [ ] **接入服务商**：与实际使用的服务商一致
- [ ] **网站类型**：选择"非经营性互联网信息服务"
- [ ] **前置审批**：确认无需要前置审批的业务，选择"无"
- [ ] **网站服务内容描述**：≥ 15 字，清晰描述"校园技术社团服务平台"定位
- [ ] **所有上传材料**：清晰、完整、无遮挡

### A.3 失败回退路径（审核被退回 / 备案失败）

| 退回原因 | 处理方案 |
|---|---|
| **域名未实名 / 实名不一致** | 到域名注册商完成实名认证；确保域名所有者与主办单位名称完全一致 |
| **服务器 IP 不在境内** | 更换境内服务器，或使用境内接入服务商的服务器资源 |
| **网站服务内容描述不合格** | 参考附录 A.1 修改描述文本，确保"非营利性校园社团"定位清晰 |
| **材料不清晰 / 不完整** | 重新拍摄高分辨率扫描件；确保证件四角完整、文字清晰可辨 |
| **主体信息有误** | 核对法人证书与填写信息，修正任何错别字或简称 |
| **被要求补充材料** | 按管局通知要求，在规定时限内补充指定材料并重新提交 |

### A.1 网站服务内容描述（预写模板，≥ 15 字）

> **本段对应备案系统中「APP/网站运营的服务内容、服务功能、服务用途」文本框。**

本网站为高等院校计算机协会官方网站，面向在校学生提供技术社团的在线服务。主要服务内容包括：社团介绍与入社申请、技术活动发布与报名签到、校园技术社区交流（发帖、评论、点赞、收藏）、学习工具集（在线考试、资源库、任务发布、积分激励、学习助手）。网站用于促进校园技术交流与学生实践能力培养，服务对象为在校师生，不涉及经营性活动。

### A.3 技术架构简述

> 备案系统通常不要求提交详细技术架构，以下仅供了解。

网站采用前后端分离架构：浏览器 → Next.js 前端（BFF 薄转发）→ FastAPI 后端 → PostgreSQL 数据库。前端负责 UI 渲染与 API 代理，后端承载全部业务逻辑与数据持久化，数据库使用 PostgreSQL。部署方式为 Docker 容器化 + 外部反向代理（Nginx/Caddy）HTTPS 加密传输。

## 附录 B：安全与用户信息处理说明（填写备案表单时参考）

> 备案系统可能要求填写"用户信息处理说明"或"安全防护措施"，以下内容**仅用于辅助填写**。

### B.1 安全防护措施简述（供备案参考）

- **身份认证**：采用 JWT 双令牌（access token 短效 + refresh token 长效）+ TOTP 双因素认证（可选），密码使用 bcrypt 哈希存储。
- **访问控制**：基于角色-权限模型（RBAC），每个 API 端点独立校验权限。
- **传输安全**：全站 HTTPS 加密传输，Cookie 使用 Secure + HttpOnly 标记。
- **数据安全**：敏感操作审计日志、异常日志独立存储、密码/2FA 密钥加密存储。
- **内容安全**：UGC 内容先发布后审核，图片上传经大小/类型/魔数四重校验。

### B.2 用户信息处理简述（供备案参考）

- **收集信息**：账号信息（用户名、邮箱、密码哈希）、个人资料（昵称、头像、技术标签）、设备信息（登录 IP、User-Agent）、行为数据（发帖、评论、活动记录）。
- **存储与保护**：全部数据存储于服务器 PostgreSQL 数据库；HTTPS 传输；密码 bcrypt 哈希；2FA 密钥 AES-256-GCM 加密。
- **使用范围**：仅用于网站自身功能实现；不向第三方出售/共享；不用于商业营销。
- **用户权利**：可查阅、更正个人资料；可自助修改密码（改密后全端登出）；可注销账号（软删除）。
