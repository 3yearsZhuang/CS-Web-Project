## 三、治理方案（分波次，一次一个独立改动点，可独立回滚）

### 波次 A · P0 行为不一致（2 项，1–2 天）
- A1 资源搜索统一（B1）：ResourceRepository 单一 `search(keyword)`（SQL ilike title+description+tags 兜底），search_service 与 auxilio 工具均透传；验证两入口结果一致。
- A2 模型默认值统一（B2）：4 处 `"gpt-4o-mini"` fallback → `settings.LLM_MODEL`；llm_config 默认值同步。
- 验收：契约零漂移 + 单元断言（搜索结果一致、改 LLM_MODEL 全量生效）+ pytest 相关用例。

### 波次 B · P1 复制漂移收敛（前端类型 + 后端复制，2–3 天）
- B1 前端类型收敛（#1–#11）：11 组类型统一 import；`TargetType` 改名 `ReplyTargetType`（#10）。
- B2 后端复制收敛（B3–B9）：7 处抽公共函数/方法。
- 验收：ts-check 10 基线零新增 + vitest + pytest；无行为变化（纯重构）。

### 波次 C · P2 样板收敛（2–3 天）
- C1 前端：use-admin-collection 工厂（#16）、EmptyState 批量替换（#24/#25）、原语替换 Spinner/Skeleton/TechTagSelector/ModalShell/Toast（#19–#22/#27）、卡片与排序条收敛（#26/#28）、joinStatusMeta/roleLabel（#12/#13/#14/#23）。
- C2 后端：分页对齐（B10/B11/B15）、常量收纳（B14）、repo 合并（B12/B13）、enrich_authors（B9 若波次 B 未做）。
- 验收：同上 + 抽查关键页面渲染。

### 波次 D · P3 + i18n 孤儿清理（0.5 天）
- D1 前端 #29 删搜索孤儿词条；D2 后端 B16/B17 清理。

### 执行纪律
- 每波独立提交、独立回滚；改动同步 SSOT（`docs/项目待办事项-优先级重排.md`）+ CHANGELOG；契约门禁全程零漂移（若涉及 API 响应结构如 B11 才显式 contract-baseline）。
- 建议先执行**波次 A**（修复真实行为不一致），再按 B→C→D 推进；每波完成后本地验收。
