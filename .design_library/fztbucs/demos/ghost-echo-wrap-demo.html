像素虚影换行错位 · 三方案预览

同一组标题在「短（单行）/ 长（换行）」两种状态下，分别呈现 现状 bug 与 A / B / C 三种修法。像素字体为项目同款 Fusion Pixel。切换下方按钮观察对比，重点看长标题下虚影与衬线标题的对齐关系。

标题状态：

现状 · Bug

echo 用 white-space:nowrap → 永远单行

衬线标题换行后，第二行背后无虚影 → 错位。

A · 跟随换行

echo 改 white-space:normal，覆盖全部行

虚影也换行，但像素字体与衬线断点不同 → 逐行水平参差。

B · 多行自动隐藏

JS 测量是否换行，换行即关虚影

仅单行标题显示虚影；多行 / 折叠顶栏一律隐藏，零错位。

C · 同断点

echo 改同字体同流 → 断点 100% 对齐

虚影与真标题同字体 → 完全对齐；代价是弱化像素字形，变为位移回声。
