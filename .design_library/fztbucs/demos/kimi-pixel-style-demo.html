03 / FEASIBILITY MAP

元素 → 项目落点对照

Kimi 元素项目落点改造范围成本
像素字体（元数据层） globals.css 新增 --font-pixel 令牌 + 局部 class 纯增量，不动现有字体栈 低
灰阶单色 Hero /join 页 Hero 区块（深色模式基调） 单页新组件，复用 motion 入场 低
CSS 月球 + 星空 替代/并存 MobiusRing（同为纯前端效果） 新增 effects 组件 <200 行 低
扫光滑动提示 Hero 底部 scroll-hint，复用 EASE 常量 mask CSS 动画，无 JS 依赖 低
像素角标 / 硬阴影按钮 Button 变体 pixel variant（组件库扩展） 新增 variant，不改默认样式 中
全屏分页滚动叙事 整页 scroll-jacking 与现有多页结构 + 无障呈冲突 高
全站像素化（含正文） 替换正文/展示字体栈 颠覆编辑式极简定位，长文可读性差 高 · 不建议
